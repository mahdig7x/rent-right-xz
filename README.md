# Rent Right

Rent Right is a peer-to-peer rental marketplace platform that enables users to rent and share items with others instead of purchasing them. The platform helps reduce unnecessary spending, promotes resource sharing, and allows item owners to generate value from underutilized belongings.

## Live Demo

https://rent-right-xz.lovable.app/

## Project Overview

Many items such as camping equipment, grills, lamps, and other outdoor tools are only needed occasionally. Rent Right connects people who need these items with people who already own them, creating a convenient rental ecosystem.

The platform allows users to:

- List items for rent
- Browse available listings
- Search for specific items
- View nearby listings
- Book rental items
- Communicate with item owners
- Pay rental insurance
- Submit reviews and ratings
- Report issues and disputes

## Key Features

### For Renters

- Browse available listings
- Search items by category
- View item details
- Book rental items
- Pay insurance fees
- Contact item owners
- Rate and review lessors
- View booking history

### For Lessors

- Create rental listings
- Upload item photos
- Manage listings
- Accept or reject booking requests
- Communicate with renters

### For Administrators

- Manage users and listings
- Handle reports and disputes
- Monitor platform activities
- Transfer insurance compensation when required
